# PROVN Visual Assets — Export Slots

The folders in this directory are intentionally reserved for final exports from the Figma source. Add the approved artwork yourself; do not use provisional or reconstructed logo images.

## `logo/`
Add the final logo exports, preferably SVG for scalable artwork and PNG for transparent raster use. Suggested exports:
- Primary horizontal wordmark
- Vertical/stacked logo
- Standalone symbol
- App icon variations, if needed

## `brand/`
Add:
- `PROVN-Brand-Identity-Board.png` — the complete one-page identity board
- `PROVN-Color-Palette.png` — optional standalone palette image
- Optional logo-on-background examples

## `social/`
Add any final social cover or portfolio presentation graphics you choose to include.
